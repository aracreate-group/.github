# .github

The org-level meta-repository for **araCreate Group**. It holds the public
organisation profile and org-wide GitHub defaults — not a software project.

| Path | Purpose |
| :--- | :--- |
| [`profile/README.md`](profile/README.md) | The organisation landing page rendered at [github.com/aracreate-group](https://github.com/aracreate-group). GitHub mandates this exact path. |
| `profile/assets/` | Images referenced by the profile, via absolute raw URLs. |
| `docs/` | Notes and reference material for maintaining the profile. |

This repo must stay **public** for the profile to render.

## Conventions

Follows [aracreate-conventions](https://github.com/aracreate-group/aracreate-conventions).
As a meta-repo with no source code, it applies the parts that fit — layout,
file headers, licensing, and Git rules — and omits the software scaffold
(`src/`, `tests/`, `releases/`, `Makefile`, `VERSION`).
